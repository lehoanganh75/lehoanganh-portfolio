## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/lehoanganh75/lehoanganh-portfolio.git
cd lehoanganh-portfolio
```

### 2. Run the backend server

```bash
cd server
npm install
npm run dev
```

### 3. Run the frontend client

Open a new terminal:

```bash
cd client
npm install
npm run dev
```
